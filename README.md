# Friends of Cutter / Reinhart Park

Community website for Friends of Cutter / Reinhart Park in Arlington, MA.

Built with [Jekyll](https://jekyllrb.com/) using the [Beautiful Jekyll](https://beautifuljekyll.com/) theme. Hosted on GitHub Pages at [cutterreinhartpark.org](https://cutterreinhartpark.org).

## Local Development

```bash
bundle install
bundle exec jekyll serve
```

Site will be available at http://localhost:4000.
